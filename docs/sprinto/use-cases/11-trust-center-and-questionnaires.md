# UC-11 — Trust Center and security questionnaires

## Situation

Prospects and customers request security documentation and send questionnaires; the security team becomes a bottleneck in sales cycles.

## Actors

- Sales / customer success
- Security / GRC (answer owners and approvers)
- Prospects and customers (self-serve)

## Trigger

Deal-stage security review, vendor onboarding at a customer, renewals, RFPs.

## Flow

### Trust Center
1. Configure branding, sections and real-time control posture; publish on Sprinto or custom domain; multiple centers per product/region (Enterprise Trust).
2. Gate documents behind clickwrap NDA or DocuSign/HelloSign; private profiles; access expiration; automated access requests handled in-app or Slack.
3. Visitors subscribe to updates; engagement analytics; Ask AI assistant on the Trust Center.

### Questionnaires
1. Import questionnaires (files or portals); centralized, self-improving knowledge base and Knowledge Hub.
2. AI drafts answers; tag-based tailoring by product/region/industry; assign questions, comment, approve.
3. Chrome extension / Sprinto Assist fills third-party portals and attaches evidence; tracked copy saved.
4. Pipeline tracking of questionnaire status.

## Sprinto capabilities used

Trust module · Trust Center · Questionnaires · Knowledge Hub · Security Questionnaire AI · browser extension · DocuSign/HelloSign · DSR and responsible disclosure portals.

## Outcome

Faster deal cycles; fewer repetitive questionnaire hours; current, self-serve posture for buyers.
