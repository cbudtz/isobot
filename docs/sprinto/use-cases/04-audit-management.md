# UC-04 — Audit management and auditor collaboration

## Situation

External (compliance), internal or custom audits must be planned, evidenced and closed, often with several in flight.

## Actors

- Audit owner (GRC lead)
- External auditor (Sprinto network, A-LIGN integration, or BYOA)
- Internal audit team (Growth tier)
- Control owners responding to requests

## Trigger

Scheduled audit period, customer-mandated audit, or internal audit calendar.

## Flow

1. **Create audit** — Choose type (automated, partner, custom), define period and requirements; import or customize controls and criteria.
2. **Configure evidence** — Select which staff and risk registers are included; evidence auto-mapped from checks.
3. **Collaborate** — Auditor gets secure in-app access; in-app communications channel; custom request lists and evidence task workflows.
4. **Score & review** — Auditor scoring fields and review statuses per requirement.
5. **Findings** — Findings and remediation tracker; tasks assigned to owners.
6. **Report** — Audit lifecycle reporting; rolling audit packs; signed evidence exports.

## Sprinto capabilities used

Audits module (independent module available) · Evidences (versioning, bulk/CSV, search) · auditor network and Audit Partner API · internal audit management · findings tracker · tamper-evident logs.

## Outcome

Shorter fieldwork; fewer request round-trips; evidence pre-verified before the audit starts.
